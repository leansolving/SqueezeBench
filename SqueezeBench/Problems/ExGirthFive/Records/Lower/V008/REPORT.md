# ExGirthFive, lower record, V008

By trial claude-fable.

## How the bound was obtained

**Bound.** `record n = max (V007 n) (max over the table of primes p of blk p n)` with

```
blk p n  = p³ · ⌊n / (2p²)⌋ + part p (n mod 2p²)
part p r = s · (r − s·p)        where s = ⌈r / (2p)⌉   (truncated subtraction)
```

over a table of 217 primes: `2, 3, 5, 7`, one prime near the geometric mean of each pair of
consecutive entries of the V007 table (which had ratio about `1.19` between entries; the merged
table has ratio about `1.09`), and the V007 table itself (reused by name from V007's `Def.lean`).

**Idea.** V006 and V007 place `⌊n/(2p²)⌋` disjoint copies of the point–line incidence graph of
the affine plane over `ZMod p` (points `(x, y)`, lines `y = a x + b`, `p³` edges on `2p²`
vertices, girth `6`) and leave the `r = n mod 2p²` leftover vertices isolated. The leftover now
carries an induced subgraph of one more plane: `s` complete parallel classes (all `s·p` lines of
slopes in a set `A` of size `s`) together with a set `P` of `m = r − s·p` points. Every point is
on exactly one line of each class, so this piece has exactly `s·m` edges, and as an induced
subgraph of the plane it keeps girth `6`. The choice `s = ⌈r/(2p)⌉` balances the two sides:
`s·p ≈ m ≈ r/2` and about `r²/(4p)` edges. Between two consecutive table primes the envelope of
these bounds stays above `0.82 · (n/2)^{3/2}` (model computation over `n ≤ 2^60`), where V007
fell to `0.59 · (n/2)^{3/2}` just below a block size. The primes `2, 3, 5, 7` extend the
construction down to `n = 8`: `C₈` at `p = 2`, the Pappus graph at `p = 3`.

This is the classical "delete vertices from the incidence graph" argument used for the small-`n`
lower bounds in the literature (Garnick–Kwong–Lazebnik 1993), applied uniformly to every `n`.

**Values.** `record 1000 = 10868` (V007: `6859`; conjectured truth `(n/2)^{3/2} ≈ 11180`),
`record 100 = 343`, `record 50 = 125`, `record 10⁶ = 344577206`. The record beats V007 at 2869 of
the first 3000 values of `n`; the exceptions are `n ≤ 7`, `n ∈ {9, 10, 11, 13}` and short runs
just above each block size `2p²`, where V007 already has the full plane and the sub-plane on the
few leftover vertices is empty.

## How the proofs were obtained

Written by the AI agent named below, in Lean, without automation beyond Mathlib's tactics.

- `transport_le`: a girth-`5` graph on any finite type with at most `n` vertices, with `#I`
  distinct edges exhibited by an injection `I → Sym2 V`, gives `#I ≤ f n`. It is the transport
  step of V006's `block_le` (embedding into `Fin n` by `Function.Embedding.nonempty_of_card_le`,
  `cliqueFree_map_iff`, and the injectivity argument for `NoTwoCommonNeighbours`), stated once
  for reuse.
- `comap_noTwo`, `comap_cliqueFree`: both halves of the girth condition pass to the pullback
  `G.comap φ` along an injection (`CliqueFree.comap` with the copy given by `Embedding.comap`).
- `subplane_le`: for a prime `p`, `s ≤ p`, `m ≤ p²` and `k·2p² + s·p + m ≤ n`,
  `k·p³ + s·m ≤ f n`. The vertex type is `Fin k × Side p ⊕ (P ⊕ A × ZMod p)` with `P`, `A`
  finsets of the right cardinalities (`Finset.exists_subset_card_eq`), mapped injectively into
  `Fin (k+1) × Side p`, the vertex type of V006's `PG (k+1) p`; the graph is the pullback. The
  edges are indexed by `Fin k × (ZMod p)³ ⊕ (P × A)`; the sub-plane edge of a point `q` and a
  class `a` is `s(q, line (a, q.y − a·q.x))`, which `simp [PG, sadj]` verifies. Cardinalities
  are `simp` with `Fintype.card_coe` and `ring`.
- `part_spec`, `blk_le`: the arithmetic that `part p r` is a valid `(s, m)` for the leftover
  `r < 2p²` (`s ≤ p` from `Nat.div_lt_iff_lt_mul`, `m ≤ p²` from `2·s·p ≥ r`), with the case
  `r < s·p` (where `part p r = 0`) taken as the empty sub-plane. Nonlinear terms are handled by
  naming them and `omega`.
- `primes_prime`: `norm_num` on the 107 new entries, `V007.primes_prime` for the rest
  (`List.forall_mem_append`). `blocks_valid` is V007's list induction with `blk_le` in place of
  `V006.block_le`. `valid`, `improves`, `strict` are the `maxWith` idiom; `strict` is
  `decide +kernel` at `n₀ = 1000`.

Nothing was abandoned; the first design (pullback of `PG` along an injection from a sum type)
went through directly.
