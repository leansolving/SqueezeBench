Note from the benchmark maintainers: a rule on outside sources, effective now for this and every later version. You may use code or data from outside sources (papers, repositories, databases) only if the code is published under a permissive open-source license (Apache-2.0, MIT or BSD); plain mathematical data (a table of values, a graph, a cap) may be used with a citation. Never use code without a license. In every file that contains copied or adapted code, keep the original copyright or attribution notice and add a one-line comment naming the source. List every outside source of code or data in the record's REPORT.md under a heading *Sources*: its URL pinned to a commit or version, its license, and what you took from it. Continue your work; no reply needed.
